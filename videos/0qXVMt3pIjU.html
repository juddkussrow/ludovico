This $8 Microcontroller Is Running a Language Model Locally!

@octopusinc_ · 2026-07-31 · Hardware

This video demonstrates running a 28.9 million parameter language model, TinyLLM, on an $8 ESP32-S3 microcontroller using a memory optimization technique called Per-Layer Embeddings, inspired by Google's Gemma. The creator walks through the process of flashing the model onto the hardware and testing its text generation capabilities, highlighting its limitations and the underlying technical innovations. The project leverages Andrej Karpathy's llama2.c as a blueprint for running small language models in C on embedded systems.

This is achieved using a "Per-Layer Embedding" trick, inspired by Google's Gemma architecture. The trick involves storing the majority of the model's parameters (a 25 million row embedding table, approximately 15MB) in the slower, cheaper 16MB flash memory of the ESP32-S3, and only loading the necessary 450 bytes (six rows, one for each of the model's six layers) into the fast SRAM for computation. The model is trained on the TinyStories dataset, designed for small models to learn coherent storytelling. The project builds upon Andrej Karpathy's llama2.c, which demonstrates running small LLMs in plain C without an operating system or Python interpreter. The creator provides a one-shot `build_and_flash.sh` script to automate the setup, training, and flashing process, which takes about 25 minutes, with most of the time spent on training the TinyStories model (30 minutes on a MacBook). The model generates text at approximately 9 tokens per second (104.5 ms/token). A limitation is that custom prompts require re-flashing the ESP32, as it can only play back one pre-flashed prompt at a time. During testing, the model consistently drifts back to a story about a little girl, even with different prompts like "a robot" or "a long time ago in a galaxy far far away," indicating its limited understanding beyond its training data. The specific ESP32-S3 variant required is the N16R8, which has 16MB of flash and 8MB of PSRAM.
