The video presents "Points as Tori" (PAT), a novel algorithm for fast pointwise signed distance estimation from point clouds. PAT uses a pre-trained neural network to fit local tori to point neighborhoods, leveraging the closed-form Signed Distance Functions (SDFs) of tori to efficiently approximate the true signed distance of an underlying surface. This method offers improved accuracy and speed compared to existing techniques, particularly for sparse point clouds, without requiring global solves or spatial discretization.

The core problem addressed is that existing fast reconstruction algorithms do not compute true signed distance, and methods that do are often computationally expensive or struggle with accuracy. PAT leverages a simple kernel density estimator, where per-point functions are defined using tori. Tori are chosen because they can locally approximate surfaces up to second order and have efficient closed-form Signed Distance Functions (SDFs). The method involves a pre-trained transformer-based neural network that takes a point and its k-nearest neighbors as input and outputs six polynomial coefficients to fit a torus. This network is trained on 10,000 models from the ABC dataset and 2,000 procedural shapes, taking approximately 45 hours on a single NVIDIA RTX 3090 GPU. The pre-training is a one-time process, and the network is purely local, allowing it to be applied to any input point cloud. Inference involves applying the pre-trained network to each point neighborhood (which is parallelizable) and then evaluating the SDF using a simple analytical formula, making queries fast. PAT avoids the issues of previous convolutional distance formulas which often give distance to sampled points rather than the underlying surface, and it does not require global solves or spatial discretization. The method demonstrates better reconstruction quality than other fast point-based methods like winding numbers and provides distance information. For sparse point clouds, PAT outperforms the sign heat method, and while NN-VIPSS might produce better reconstructions for sparse point clouds, PAT is significantly faster. Across four datasets, PAT showed lower error and faster computation times, sometimes by orders of magnitude, compared to other approaches for signed distance computation. A key design choice is intentionally not learning end-to-end, as the eikonal equation is nonlinear and has many local minima, making end-to-end learning difficult and inference expensive. Instead, PAT uses learning for the local torus fitting component, which has no easy analytical solution, and reuses this network across problems for faster inference.
