OpenWiki is an open-source command-line interface (CLI) tool from LangChain that automatically generates and maintains documentation wikis for codebases, specifically designed for AI coding agents. It creates structured markdown documentation, refreshes it upon code changes, and integrates with agent configuration files (AGENTS.md, CLAUDE.md) to ensure agents utilize the generated context. The tool supports various LLM providers and can be integrated into CI/CD pipelines for automated documentation updates.
