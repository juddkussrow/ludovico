How To Remotely Connect Ollama With Coding Agents

@octopusinc_ · 2026-08-27 · DevOps

This video demonstrates how to remotely connect Ollama, running a self-hosted model like TinyLlama, to coding agents or other consumers using the Pangolin AI gateway. The process involves setting up Ollama as a custom provider within Pangolin, establishing a secure outbound-only VPN tunnel via a Pangolin site connector, and then configuring an AI gateway resource to expose the Ollama instance. This setup allows for secure, authenticated access to local AI models without traditional VPNs, providing features like keyless authentication, access control, and detailed session logging.
