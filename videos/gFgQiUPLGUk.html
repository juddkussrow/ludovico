Unlazy functions as a "completion discipline" for AI agents, using runnable checks and an "acceptance ledger" (gates.md) to verify work. Each gate in `gates.md` requires a `CHECK` line (a shell command) and an `EXPECT` line (a success marker in the output). A gate is only considered met if the command exits with code zero and the `EXPECT` text is found in the output. Evidence of successful execution is then written into the ledger, including the resolved shell, working directory, exit status, path fingerprint, and decisive output. If a gate is genuinely impossible, it must be marked with an `abandon` line and a reason. Unlazy is implemented as a skill, compatible with Claude Code and Codex CLI, and built on Node 16+. Installation is via `npx skills add leong x/unlazy` or manual cloning. It supports natural language triggers. For solo tasks, users copy a template to `gates.md`, fill in gates, and then run `gate-check.js` with `--status` (report-only mode) or `--approve` (to execute commands after review). The `--approve` flag binds approvals to specific ledger, gate, check, expect text, working directory, shell, timeout, platform, and path, requiring re-approval if any change. A `--reverify` flag re-runs all gates, including completed ones, for re-execution. For larger tasks, Unlazy uses a "depth tree" orchestration, splitting tasks into "leaves" with their own `gates.md` files and file ownership. A `plan.md` defines interfaces and dependencies. Integration gates are used for branches. Leaves declare `OWNS` paths to prevent concurrent writes. Verification flows upward, with parent tasks re-verifying leaf gates. Claude Code has an optional "stop hook" that prevents early completion if unmet gates exist, with a built-in escape valve after six consecutive blocks without progress. The project's `README` is noted for its honesty, citing research on LLM laziness without making unsupported benchmark claims. The creator praises Unlazy for moving the definition of "done" into a verifiable file, its security-conscious approval system, zero dependencies, and honest documentation.
