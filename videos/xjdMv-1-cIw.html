Cleanup involves using "group create" and "blast" nodes to remove unwanted points from the scene. To enable relighting, a "normals from splats" node is applied to generate normal information, with a voxel scale of 1 being effective for the demonstrated environment. The scene is then moved to Solaris, Houdini's rendering environment, where a "SOP import" node brings in the prepared splats. The renderer is switched from Houdini VK to Karma XPU. Relighting is achieved using "dome light" and "labs relight G splats" nodes, allowing for non-destructive exploration of various lighting scenarios. A camera is set up, and render settings are configured, specifically changing the engine from CPU to XPU parameters for faster rendering. The tutorial then delves into creating a Pyro smoke simulation. This involves generating an emission source (a sphere deformed with a "mountain" node), positioning it, and then using "pyro source," "volume rasterize attribute," and "pyro solver" nodes. Key pyro solver settings adjusted include disabling flame and velocity, setting temperature source to density, reducing buoyancy to 0.01, enabling surface turbulence and shredding (0.5), increasing turbulence (5), adding viscosity, and setting wind to 3 with a diagonal direction. A "pyro bake volume" node is used with density scale 25 and shadow density 2. The simulation is cached using a "file cache" node for performance. Finally, the smoke simulation is imported into Solaris via another "SOP import" node to be lit and composited with the Gaussian Splats.
