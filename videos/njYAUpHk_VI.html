360 Gaussian Pro is a desktop application designed for creating 3D Gaussian Splatting models from 360-degree video footage. It streamlines the process from raw input to a trained model by handling frame extraction, AI-powered masking with SAM 3, and camera alignment. The tool supports various input types, including raw fisheye and stitched equirectangular video, and integrates with external training backends like Lickfeld Studio.
