This video introduces Destructive Command Guard (dcg), a Rust-based safety hook designed to prevent AI coding agents from executing destructive shell and Git commands. It acts as a PreToolUse hook, screening commands in sub-millisecond latency and blocking dangerous operations like `rm -rf` or `git reset --hard` while allowing safe variants. The tool features a four-stage pipeline for command evaluation, supports various AI agents, and is open-source with a fail-open design.
