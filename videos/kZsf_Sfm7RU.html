Unlike traditional software, agent failures often don't crash systems but manifest as "invisible failures" in conversations, where an agent might technically succeed but fail the user's task. This necessitates a new operational paradigm where agents monitor and improve other agents. Wandero AI employs a suite of specialized agents for this purpose. The "Log-Monitor Agent" continuously analyzes production logs and agent trajectories, detects problems, and can either send Slack alerts for critical issues or generate pull requests (PRs) with proposed fixes, including descriptions, metadata, and diagrams (Mermaid or ASCII). The "PR-Review Agent" then reviews these PRs from a "different angle," running focused tests (e.g., typecheck, lint) and determining if the proposed fix addresses the root cause or just a symptom. It can request changes or close PRs, with human approval at the merge boundary. The "Session-Analyzer Agent" provides a high-level health score for the system by analyzing every user session for outcome, quality, cost, and issues, collapsing patterns to identify systemic problems. It generates AI insights and recommendations for fixes, displayed on a dashboard showing score distribution, intent performance, tool usage, and detailed session analysis. Finally, a "QA/Computer-Use Agent" simulates user interaction by opening browsers, logging in, and performing actions to detect UI-related issues that logs might miss. The speaker emphasizes that these agents require comprehensive access to logs, trajectories, codebases, databases, and live UIs to function effectively, forming a "meta harness" that closes the loop on agent operations.
