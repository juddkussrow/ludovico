Archify is an open-source developer tool that enables AI coding agents to generate architecture diagrams by outputting structured, typed JSON that is then validated and rendered into interactive HTML. This process prevents AI hallucinations by ensuring the diagram accurately reflects the codebase through repository evidence and strict validation. The tool supports interactive exploration of system paths, architecture diffs for code reviews, and various diagram modes, making it suitable for PRs and design documentation.
