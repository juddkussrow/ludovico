The Base Model Is Dead — Varun Singh, Arcee AI

This video argues that the traditional concept of a base model, primarily trained on vast amounts of web text, is outdated. Modern base models, exemplified by projects like Nemotron and Arcee AI's Trinity, increasingly integrate instruction data, synthetic reasoning traces, and post-training data earlier in the training process to better prepare them for downstream tasks and reinforcement learning. The shift emphasizes building priors for reasoning and agentic behavior rather than just mirroring the internet.

Historically, base models like GPT-3 were primarily trained on vast amounts of web text (e.g., Common Crawl, WebText-2, Books, Wikipedia), with web text comprising up to 85% of the training mix. Post-training then focused on adapting the model for chat interfaces. However, with the advent of advanced reinforcement learning (RL) and reasoning models (like OpenAI o1 and DeepSeek R1), the role of the base model has shifted. Modern base models now incorporate instruction data and synthetic reasoning traces much earlier in the training process. For instance, Llama 3's data mix still has a majority of general knowledge tokens, but web text is taking a backseat to code and STEM abilities. Projects like Nemotron 3 Ultra explicitly pull post-training data and large-scale synthetic data into pre-training, using SFT-prefixed datasets to teach the model conversational shapes and downstream tasks from the start. In contrast, MAI-Base-1 attempts to avoid synthetic data, but its data mix still significantly reduces web text's proportion to around 15%, with code becoming a dominant data subset. Arcee AI's Trinity model uses synthetic data through rephrasing to upsample seed data items. The video highlights that adding post-training data early is beneficial for Mixture-of-Experts (MOE) models to prevent load balancing issues, as seen in MAI-Base-1. A distinct "mid-training" stage has emerged for longer context pre-training, exposing models to post-training distributions and agentic traces. The speaker suggests viewing LLM training as two broad paradigms: supervised learning (which builds priors for RL) and RL itself, with RL increasingly dominating the compute budget. Supervised learning's role is now to prepare the model for RL, building "atomic skills" that RL can then compose. Novel data, such as reasoning traces and data for test-time compute schemes, are also being introduced during supervised learning, as exemplified by ZAYA1-8B.
