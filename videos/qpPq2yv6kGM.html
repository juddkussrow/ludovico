hardware - mentioned SYNOPSIS: The video introduces the "Hex Grid Nest," an expansion to the Duality Hex Grid system, designed for creating modular LED displays. The core innovation is splitting hexagon segments into two lanes with a divider, allowing each hexagon to be wired as an independent element with data in and out, simplifying routing. This creates a "nested hexagon matrix display" where each hexagon can control its color and light pattern. The project uses 3D printed parts for the hexagonal frames and diffusers. The creator demonstrates a symmetrical 10-hexagon pattern, with each hexagon comprising six 200mm LED strips (24 pixels) and an optional perimeter strip of 22 200mm strips (88 pixels). Power wires are routed for convenience, while data wires are connected in series. Three base options are presented for housing the electronics: a compact base for a Seed Studio ESP32C3, buck converter, and optional logic level shifter; a developer base for a full-size ESP32; and a larger base for various WLED controllers. The assembly involves mounting components to a backplane and sliding it into the base. A logic level shifter is recommended for smaller ESP32s to convert 3.3V logic to 5V. The LED strips are considered the power source for the base circuit, with Vin from the buck converter soldered to 12V on the strip. Wires are added between segments for a cleaner look, or narrower 5mm strips can be used continuously. Silicone putty is used for cable management and light blocking. WLED is installed on the ESP32 via a USBC data cable, and the WLED app is used for configuration. GPIO4 is used for hexagon strips (grouped in 24-pixel segments), and GPIO21 for the perimeter strip (88 pixels). Standard WLED effects are used for patterns. Mounting is done with foam mounting tape and a single screw for leveling. The system is designed for closed loops and redundant connections, eliminating the need for power injection.
