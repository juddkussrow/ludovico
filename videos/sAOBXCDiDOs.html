Pietro Zullo, co-founder of Manufact, explains that MCP Apps are full interaction layers, bidirectional and stateful, rendered by the host in a sandboxed iframe. Manufact provides open-source SDKs and dev tools for MCP, including `mcp-use` for building (8M+ downloads, 10K GitHub stars) and `Inspector` for testing. Manufact also offers a cloud platform for shipping MCP servers. The timeline of MCP evolution is presented: MCP launched in Nov 2024, `mcp-ui` in May 2025, ChatGPT Apps SDK in Oct 2025, stores opened in late 2025, and MCP Apps became official in Jan 2026. An MCP App works by having the model call a tool, which returns a UI widget in a sandboxed iframe. This allows for bidirectional communication. Key primitives include `ui/update-model-context` for the app to push live state into the model's context, and `ui/message` for the app to send messages back to the conversation. Another primitive is streaming tool input, where the model streams tokens into the widget, and the UI updates incrementally, as demonstrated with Excalidraw. A pattern called "Tell the model less than you show" allows the UI to display full information while the model only receives a redacted summary, addressing privacy concerns. Real-world examples of MCP Apps are shown in Cursor (analytics), Claude (Excalidraw for diagrams), and ChatGPT (analytics). The speaker notes that client support varies, with some clients like Claude displaying messages in the chat input for user confirmation, while OpenAI directly sends them. `mcp-use` simplifies building these apps, allowing developers to define tools that return React components as widgets. Distribution occurs through app stores on platforms like ChatGPT, Claude, and Cursor, which offer self-serve submission processes. Manufact assists with vetting and generating submission artifacts. A crucial aspect is dynamic discovery, where clients like Claude can search the MCP registry for relevant connectors based on user intent, even before installation.
