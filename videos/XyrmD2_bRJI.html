celld is an open-source, self-hosted Rust daemon from Deno that allows users to run Cloudflare Workers and Durable Objects code on their own infrastructure without changes. It significantly reduces costs compared to Cloudflare's managed service by leveraging an S3-compatible bucket for coordination and SQLite for per-cell storage, achieving durability through LTX replication. The tool offers a cost-effective alternative for deploying stateful logic with a focus on reliability and ease of deployment.
