The Colonel Panic Flock Camera Detector is a small, ESP32-based device that uses promiscuous Wi-Fi to detect Flock cameras by their OUI (first six characters of a Bluetooth MAC address) and buzzes when detected. It can be purchased as a complete device or built from components for under $10. EFF's Rayhunter is an open-source software that runs on mobile hotspots (costing $20-$40) to detect IMSI catchers (stingrays) by analyzing control traffic between a modem and a cell tower. It alerts users if suspicious activity is found and allows downloading packet captures for further analysis. The Biscuit Ultra is a war driving gadget that records nearby devices, detects Flock cameras and Bluetooth devices, and has an anti-surveillance feature that alerts the user if the same device is detected repeatedly, suggesting they are being followed. Meshtastic, running on devices like the LilyGo T-Deck or Exploitee.rs Meshtastic Pager, enables off-grid, mesh network communication using LoRa technology (915 MHz in the US), allowing messages to hop between devices across significant distances. The video emphasizes the accessibility and DIY nature of these tools, empowering individuals to counter surveillance.
