This video introduces Eve, a new agentic framework by Vercel, designed to simplify agent building by adopting file system conventions similar to Next.js. The speaker, Andrew Qu, details Vercel's journey in developing an internal data science agent, evolving from mega-prompts to chained agents, and finally to a single state-managing agent, before the "file system unlock" inspired by Claude Code. Eve aims to provide a structured yet flexible environment for creating company-specific agents, enabling rapid development and deployment.

Initially, Vercel's internal data science agent started as a "mega prompt" where a Snowflake schema was pasted, and SQL was manually run. This evolved into a chain of narrowly scoped agents for planning, execution, and reporting, each with dedicated system prompts and tools. The third iteration was a single agent managing its own state, capable of reflection and error recovery. However, initial rollout was met with negative feedback. The "unlock" came from observing Claude Code's effectiveness with a simple file system (list, read, bash tools). This led to rebuilding the agent in a sandbox with the semantic layer, doubling the evaluation score. Vercel then developed a system to distill common queries into "skills" (around 100 currently), allowing agents to start with accumulated context. This approach inspired Eve, a framework released two weeks prior to the talk, which applies Next.js's file system conventions to agents. Eve provides a runtime for durable execution, state persistence, and event streaming, integrating with Vercel's AI SDK, Sandbox, Workflows, and Connect. It supports various channels like Slack, Discord, and Web Chat. Eve is open-source friendly, allowing custom adapters for Postgres, OpenAI, and Docker, while also being optimized for deployment on Vercel. A beta customer, Aura, rebuilt their agent using Eve, reporting fewer steps, better success rates, and improved insights compared to off-the-shelf Claude Code. Qu emphasizes building narrow, company-specific agents over general ones, noting Vercel has about twenty such agents in use, saving significant time across departments.
