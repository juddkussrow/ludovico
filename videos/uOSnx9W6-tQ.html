Herdr: Free Open Source Agent Runtime Hits 1M Installs

@octopusinc_ · 2026-09-26 · DevOps

Herdr is an open-source agent runtime, a Rust terminal multiplexer designed for coding agents like Claude Code and Codex. It allows agents to run persistently in the background, be herded across machines from a single window, and provides real-time status updates (working/blocked/idle). The tool has seen rapid growth, relicensed to Apache 2.0, joined Y Combinator, raised $6M, and now supports remote machine control and a large plugin marketplace.
