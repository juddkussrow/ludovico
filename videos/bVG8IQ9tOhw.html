Run Firecrawl for Free in the Cloud (No Credit Card, No API Keys)

@octopusinc_ · 2026-06-22 · DevOps

This video demonstrates how to run Firecrawl, an open-source tool for converting web pages to LLM-ready markdown, for free in a GitHub Codespace. It details a setup that bypasses local resource consumption and Firecrawl API keys by hosting the service in a 16GB, 4-core cloud environment and tunneling it to a local machine for use with Claude Code. The process involves forking a template repository, creating a Codespace, running an automated setup script, forwarding ports, and configuring Claude Code to use the local Firecrawl instance.
