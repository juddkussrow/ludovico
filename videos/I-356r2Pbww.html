Maintainerr: 1 Free Container Cleans Plex, Jellyfin & Emby

@octopusinc_ · 2026-08-25 · Hardware

Maintainerr is a free, open-source tool that automates the cleanup of media libraries for Plex, Jellyfin, and Emby servers, integrating with Radarr, Sonarr, and Overseerr/Jellyseerr. It uses a rule engine to identify unwatched or unwanted content, moves it to a visible "Leaving Soon" collection with poster overlays indicating removal dates, and deletes it after a configurable grace period from all integrated services. The tool runs as a single Docker container and offers a responsive web interface for management.
