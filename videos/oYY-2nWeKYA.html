Vaultwarden allows users to self-host a Bitwarden-compatible server, effectively unlocking Bitwarden's premium features (like integrated authenticator, encrypted attachments, emergency access, Duo/YubiKey OTP) and organization features (unlimited sharing, user groups, directory connector, SSO via OpenID Connect) by default, without paying Bitwarden's subscription fees. The official Bitwarden self-hosting is free but requires a paid license for premium features and involves a heavier deployment (11 containers, MSSQL, though a lighter single image exists). In contrast, Vaultwarden is built on the Rocket web framework, deploys as a single binary, uses SQLite by default (with Postgres/MySQL options), and its web vault is a patched build of Bitwarden's client. Installation is a simple Docker command, but requires HTTPS via a reverse proxy. Recent security advisories (July release 1.37.0 to 1.37.2) included eight classes of bugs (e.g., SSRF, cross-org cipher access, websocket flood), all rated medium, with no CVEs assigned. Earlier SSO code had two high-rated advisories. Vaultwarden has been audited by Germany's Federal Cyber Security Agency and an external pen test team.
