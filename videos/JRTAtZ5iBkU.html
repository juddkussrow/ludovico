Therefore, HTML is presented as the ideal medium for agents to create visual content. HTML allows agents to define structure (headings, charts, grids) using tags, which browsers then render into pixels, effectively abstracting away the geospatial reasoning that agents struggle with. By using HTML, agents can produce visually rich outputs, including charts, layouts, fonts, and motion, which can then be rendered to other formats like PDF. Nori uses this HTML-centric approach to build slide decks, board decks, sales decks, documents, and even videos.
