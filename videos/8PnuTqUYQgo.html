I Gave My AI Assistant an Anime Body - Full 3D Workflow

This video demonstrates a comprehensive workflow for creating a 3D anime character and integrating it as an AI assistant using Project AIRI. The process involves character design, 3D modeling in Blender with tools like Mixamo for rigging and Faceit for blendshapes, texturing with Moddiff and Tripo, and finally exporting as a VRM model. The VRM model is then brought to life as an interactive desktop companion through Project AIRI, an open-source framework that provides a brain, voice, and reactive body to the avatar.
