SnapOtter: 200+ Free File Tools in 1 Self-Hosted Docker App

@octopusinc_ · 2026-08-30 · DevOps

SnapOtter is an open-source, self-hosted file processing suite offering over 200 tools for images, video, audio, PDFs, and general file utilities, including local AI capabilities. It aims to replace various online converters by keeping all file processing on the user's hardware, ensuring data privacy. The tool is deployed via a single Docker command and supports a wide range of architectures, including Raspberry Pi and Apple Silicon, with optional NVIDIA GPU acceleration.
