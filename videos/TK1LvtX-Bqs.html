This video reviews Xirp, Spotify's agentic development environment, a macOS application designed to manage and orchestrate AI coding agents like Claude Code, Codex, and Gemini. The tool allows users to run multiple agent sessions side-by-side, fork sessions for parallel experimentation, and even switch agents mid-task while retaining context.
