Initially, MCP servers often mapped each API endpoint to a distinct tool, which led to context window bloat and tool selection confusion for agents, especially with hundreds of endpoints. A solution emerged in the form of a layered tool call approach, where servers expose a few generic tools (search, inspect, execute) instead of hundreds of specific ones. The Neon SDK, generated from an OpenAPI spec, covers all API endpoints, with an additional layer for ergonomic methods. The `neon/tools` package converts these methods into tool calls, supporting both raw endpoints and bundled workflows. This package is used by the Neon MCP server and can be adapted for various agent frameworks like Mastra and Eve, with tools organized into categories for scope control.
