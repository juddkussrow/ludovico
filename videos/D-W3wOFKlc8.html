Laya, licensed under Apache 2.0, processes text, email, tickets, or JSON to answer typed questions (choice, score, yes/no probability) in a single forward pass. It is built on an encoder, not a chat model, with the main checkpoint using a ModernBERT-large with 421 million parameters. Laya comes in three checkpoints: a base English model (515 tokens context), a multilingual model (mmBERT-base, 322M params, 100+ languages, 1024 tokens context, 2x faster), and a Laya-typed-decisions model fine-tuned for business processes. Benchmarks show Laya outperforming Jev in several public tests, including typed-decisions (76.6% vs 72.7%), AG News (95% vs 91%), and emotion tests (59.5% vs 48%). Laya is also significantly faster, with a p50 latency of 32.8 ms per question compared to Jev's 236-276 ms, making it 7-8 times quicker. Its calibration error is also three times lower. However, Jev excels in scenarios with a large number of options (e.g., Banking77 with 77 categories, Jev scored 87% vs Laya's 42.5%), as Laya's fixed token budget can blur labels with too many options. Jev supports up to 255 options, while Laya struggles with over 20. The video demonstrates Laya's live demo on Hugging Face Spaces, showcasing its use for support triage, email/phishing detection, LLM guardrails, and a playground for custom queries. The demo shows Laya classifying customer messages, identifying phishing attempts, and detecting jailbreak prompts. Installation is a single `pip install laya` command, with fine-tuning possible via a provided notebook on Kaggle's free T4 GPUs.
